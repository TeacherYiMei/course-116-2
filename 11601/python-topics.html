👋 P1｜print()：程式怎麼「說話」？

輸出字串執行順序
核心觀念：程式執行時通常由上往下。print() 的工作，是把括號裡的內容送到畫面上。引號包住的內容叫做「字串」，代表文字資料。

看懂這段程式

print("早餐準備好了")
print("記得帶水壺")
電腦腦內流程：
  1. 讀到第一行 → 顯示第一句。
  2. 再讀第二行 → 顯示第二句。
  3. 兩個 print() 會產生兩次輸出。

文字和變數不一樣

city = "台中"
print("city")
print(city)

第一個輸出的是四個英文字母 city；第二個才會找到變數裡保存的「台中」。引號會改變意思。

常見錯誤：忘記左右引號、左右括號不成對；或把變數加上引號，結果印出變數名稱而不是內容。
想一想：如果有 3 個 print()，通常會有幾次輸出？如果把第二行移到第一行前面，輸出的順序會怎樣？

🚌 P2｜變數＋input()：程式怎麼「記住回答」？

變數input()資料流
核心觀念：變數像「有名字的資料盒」。input() 取得使用者輸入後，如果不存進變數，後面的程式就不方便再次使用它。
drink = input("你想喝什麼？")
print("你選的是")
print(drink)
逐行追蹤：
  1. 畫面先出現問題。
  2. 程式暫停，等待使用者輸入。
  3. 回答被放進 drink 這個變數。
  4. 之後只要寫 drink，就能取出剛才的回答。

為什麼不同資料要用不同變數？

animal = input("喜歡的動物：")
color = input("喜歡的顏色：")

如果兩次都存到同一個變數，第二次回答會把第一次的內容蓋掉。變數名稱應該能讓自己看懂它裝了什麼。

常見錯誤：只寫 input() 卻沒有用 = 存起來；或所有答案都存進同一個變數。
想一想：如果程式需要記住「名字、興趣、年級」三種資料，你會設計哪三個英文變數名稱？

🧰 重要基礎｜Python 的資料類型

strintfloatbool
核心觀念：電腦不只要知道「資料內容是什麼」，還要知道「這是文字、整數、小數，還是真假」。資料類型會決定你可以對它做哪些運算。

四種初學最常用的資料類型

類型意思例子適合做什麼
str字串、文字"高雄"、"123"姓名、地名、訊息、文字資料
int整數12、-3、0人數、次數、年齡、整數計算
float小數12.5、0.8身高、重量、距離、平均值
bool真假True、False條件判斷，例如「有沒有及格」

看起來一樣，不代表類型一樣

a = "25"
b = 25

print(a)
print(b)

兩個都會顯示 25，但 a 是文字，b 是整數。

print(a + "5")   # 文字接在一起 → 255
print(b + 5)     # 數字相加 → 30
重要："25" 和 25 對人看起來很像，但對 Python 完全不同。

input() 得到的是什麼？

age = input("你的年齡：")
print(type(age))

即使使用者輸入 15，input() 得到的仍然是 str。要計算時，通常要轉型：

age = int(input("你的年齡："))
height = float(input("你的身高："))

資料型別轉換

寫法作用例子
int(x)轉成整數int("12") → 12
float(x)轉成小數float("12.5") → 12.5
str(x)轉成文字str(25) → "25"
bool(x)轉成真假值初學階段先知道有這種型別即可
想一想：「座號」雖然看起來是數字，但如果只是拿來辨識學生、不做數學運算，它一定非得用 int 嗎？資料類型要看「用途」，不是只看外表。

💰 P3｜變數運算：加、減、乘、除到底怎麼用？

變數運算子int()運算優先順序
核心觀念：變數不只是「保存資料」，還可以拿來計算。程式會先取得變數目前保存的值，再依照運算符號計算。

先從變數算式看起

price = 30
count = 4
total = price * count
print(total)
電腦實際做的事：
  1. 把 30 放進 price。
  2. 把 4 放進 count。
  3. 看到 price * count，先取出 30 和 4。
  4. 計算 30 × 4 = 120。
  5. 把 120 存進 total。

Python 常用數學運算符號

符號意思例子結果
+加法8 + 311
-減法8 - 35
*乘法8 * 324
/一般除法8 / 32.666...
//整除，只取完整份數8 // 32
%餘數8 % 32
**次方2 ** 38

生活情境 1：總價

price = 45
count = 3
total = price * count
print(total)

單價 × 數量 = 總價，所以使用乘法。

生活情境 2：平均分組

students = 31
group_size = 4

full_groups = students // group_size
left = students % group_size

print(full_groups)
print(left)

// 回答「可以完整分成幾組」，% 回答「還剩幾個」。這兩個符號常一起使用。

生活情境 3：折扣後價格

price = 500
discount = 0.8
final_price = price * discount
print(final_price)

八折代表原價的 80%，所以是乘以 0.8。

運算優先順序

answer1 = 2 + 3 * 4
answer2 = (2 + 3) * 4

answer1 是 14，因為先乘除、後加減；answer2 是 20，因為括號優先。

建議：如果你自己看算式時會猶豫，就加括號。讓程式「清楚」比省掉兩個括號更重要。

= 不是「答案等於」而已

score = 60
score = score + 10

第二行不是數學上的「60 = 70」。程式中的 = 是指定／賦值：先算右邊 score + 10 得到 70，再把 70 放回左邊的 score。

簡寫運算

寫法等同於意思
x += 1x = x + 1x 增加 1
x -= 1x = x - 1x 減少 1
x *= 2x = x * 2x 變成原本 2 倍
x /= 2x = x / 2x 除以 2
常見錯誤：
  • 把乘法寫成 ×，Python 要用 *。
  • 把除法寫成 ÷，Python 要用 /。
  • 忘記 input() 得到的是文字，直接拿去做數學。
  • 把 /、//、% 混在一起。
  • 不理解 x = x + 1 是「更新變數」。
想一想：有 23 顆球，每盒裝 5 顆。要知道「裝滿幾盒」和「剩幾顆」，你會分別使用哪兩個符號？

📐 P4｜float()、**、round()：小數怎麼處理？

float()次方round()
核心觀念：不是所有數字都是整數。身高、時間、距離等常有小數，此時使用 float()。round() 是整理顯示結果，不是替代計算。
radius = float(input("半徑："))
area_like = radius ** 2
print(round(area_like, 2))
看懂符號：** 2 表示平方；round(數值, 2) 表示整理到小數第 2 位。

先算，再整理

建議把問題拆成兩步：先算出真正的數值，再決定畫面要顯示幾位小數。這會比把所有東西塞在一行更容易檢查。

常見錯誤：把 ** 寫成單一 *；或誤以為 round(x, 2) 是把數字除以 2。
想一想：如果答案是 12.6789，round(答案, 1) 和 round(答案, 2) 會有什麼差別？

🧠 程式邏輯｜先想流程，再想指令

循序選擇重複流程圖思考
核心觀念：Python 指令只是工具。真正重要的是：你能不能先把問題拆成「先做什麼、接著判斷什麼、什麼時候重複」。

邏輯 1：循序 — 一步一步照順序

name = input("名字：")
score = int(input("分數："))
print(name)
print(score)

這類程式沒有分岔，也沒有迴圈，就是「第一步 → 第二步 → 第三步」。

邏輯 2：選擇 — 根據情況走不同路

temperature = 31

if temperature >= 30:
    print("天氣炎熱")
else:
    print("沒有超過 30 度")
思考流程：取得溫度 → 比較是否 ≥ 30 → True 走第一條路 → False 走第二條路。

邏輯 3：多重選擇 — 不只兩條路

score = 82

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("再加油")

程式由上往下找「第一個成立的條件」。82 不符合 90，但符合 80，所以印出 B，後面就不再檢查。

邏輯 4：固定次數重複 — for

for i in range(3):
    print("練習一次")

當你大致知道要重複幾次，常用 for。

邏輯 5：條件成立就一直重複 — while

password = ""

while password != "1234":
    password = input("請輸入密碼：")

print("登入成功")

這裡不知道使用者要輸入幾次才會正確，所以用 while：「只要還沒答對，就繼續」。

邏輯 6：把選擇放進重複裡

for number in range(1, 6):
    if number % 2 == 0:
        print(number, "是偶數")
    else:
        print(number, "是奇數")

這個程式不是只有「for」或只有「if」，而是每重複一次，都做一次判斷。真正的程式常常是多個觀念組合。

如何把中文題目轉成程式邏輯？

題目中的語意可能想到的 Python 工具
「輸入一個資料」input()
「算出結果」變數＋算術運算
「如果……否則……」if / else
「分成三種以上情況」if / elif / else
「重複 10 次」for
「一直做到某條件成立」while
解題習慣：先不要急著打程式。先用一句一句中文寫出流程，例如：「輸入金額 → 判斷是否滿 500 → 滿 500 打九折 → 顯示結果」。寫得出流程，程式通常就容易很多。

🎢 P5｜if / else：讓程式做選擇

比較True / Falseif / else
核心觀念：條件判斷不是「猜答案」，而是先產生 True 或 False。if 走條件成立的路；else 走其他情況。
height = 150

if height >= 140:
    print("可以搭乘")
else:
    print("目前不能搭乘")
電腦怎麼走：
  1. 先算 height >= 140。
  2. 如果結果是 True，只執行 if 底下縮排的區塊。
  3. 如果是 False，改執行 else 區塊。

比較符號要看清楚

> 大於、< 小於、>= 大於等於、<= 小於等於、== 是否相等、!= 是否不相等。

常見錯誤：把「比較是否相等」寫成單一 =；忘了冒號；if 區塊沒有縮排。
想一想：門檻剛好等於 140 時，> 140 和 >= 140 的結果一樣嗎？

🎫 P6｜if / elif / else：超過兩種結果怎麼辦？

elif條件順序分類
核心觀念：當結果不只兩種，就需要多條路。Python 會由上往下檢查，遇到第一個成立的分支後就停止往下比。
age = 12

if age < 7:
    print("幼兒")
elif age < 13:
    print("兒童")
else:
    print("青少年以上")
為什麼順序重要？當 age 是 5，第一個條件就成立，因此後面的 elif 不再執行。多重條件不是每一條都跑。

用區間想，不要只背格式

上面的三條路其實對應三個區間：小於 7、7 到 12、13 以上。先在紙上畫出區間，再寫程式會比較穩。

常見錯誤：把多個 if 當成 if / elif / else 使用；或條件順序排錯，讓前面的條件把後面的範圍全部吃掉。
想一想：如果第一條就寫 age < 100，後面再寫 age < 13，對 12 歲的人會發生什麼事？
📘 查 elif🚀 回闖關

🏎️ P7｜and / or：一次判斷兩件事

andor邏輯
核心觀念：and 表示「兩邊都要成立」；or 表示「至少一邊成立」。不要只背英文，要先看題目的語意是「都要」還是「其中一個即可」。
has_ticket = True
on_time = True

if has_ticket and on_time:
    print("可以進場")

用表格看邏輯

ABA and BA or B
TrueTrueTrueTrue
TrueFalseFalseTrue
FalseTrueFalseTrue
FalseFalseFalseFalse
常見錯誤：題目寫「都要」卻使用 or；或者只比較第一個變數，第二個變數根本沒有放進條件。
想一想：「有雨傘或有雨衣就可以出門」應該使用 and 還是 or？為什麼？

🚌 P8｜for + range()：有規律地重複

forrange()計數
核心觀念：當你已經知道要重複哪些數字或幾次時，for 很適合。range() 會產生一串有規律的整數。
for n in range(2, 9, 2):
    print(n)
拆開 range(開始, 停止前, 步進)：從 2 開始，每次 +2，在到達 9 之前停止，所以 n 依序是 2、4、6、8。

最重要：停止值不包含

range(1, 4) 產生的是 1、2、3，不會包含 4。這是初學者最常出錯的地方之一。

常見錯誤：以為 stop 會被包含；倒數時忘了把 step 設成負數；迴圈內的程式沒有縮排。
想一想：若要得到 3、6、9、12，開始值、停止值、步進可能怎麼設定？先不要寫完整程式，只寫 range()。

🔐 P9｜while：不知道要重複幾次時

while條件更新變數
核心觀念：while 的意思是「只要條件仍然成立，就繼續」。它不像 for 一開始就一定知道要跑幾次。
energy = 3

while energy > 0:
    print("前進一步")
    energy = energy - 1

print("休息")
三個必要零件：
  1. 迴圈開始前有一個狀態。
  2. while 有一個「還要不要繼續」的條件。
  3. 迴圈裡必須讓狀態改變，否則可能永遠停不下來。

for 和 while 怎麼選？

「重複 10 次」通常先想到 for；「一直問到答對」通常先想到 while。真正的差別是：你是在依序走一串值，還是在等待某個條件改變？

常見錯誤：while 條件永遠為 True，卻忘記更新變數，造成無限迴圈。
想一想：「使用者還沒輸入 q 就繼續問」裡，while 的「繼續條件」可能是什麼意思？

🐉 P10｜random＋while＋if：把工具組成完整程式

random分解問題整合
核心觀念：真正寫程式時，不會有人告訴你「這題只用 if」。你要先把大問題拆成小功能，再決定每一塊需要哪個工具。
import random

target = random.randint(1, 6)
guess = 0

while guess != target:
    guess = int(input("猜 1～6："))

    if guess > target:
        print("高了一點")
    elif guess < target:
        print("低了一點")

print("答對了")
這段程式其實是 4 個小問題：
  1. random：先產生一個答案。
  2. 變數：保存答案與目前猜測。
  3. while：猜錯時繼續。
  4. if / elif：告訴玩家目前太高還是太低。

寫大程式的方法：先讓核心能跑，再加功能

不要一開始就一次寫完整遊戲。先測試「隨機數有沒有產生」；再測試「能不能一直輸入」；再加入大小提示；最後才加次數、訊息等功能。

常見錯誤：一口氣寫十幾行，出錯時不知道是哪一段；或把隨機答案放在 while 裡，每猜一次答案就跟著改掉。
想一想：如果答案每一輪都重新 random，玩家還是在猜「同一個答案」嗎？為什麼 random 通常要放在迴圈外？

🧠 最後提醒：你真的理解了嗎？

能看懂別人的程式只是第一步。真正理解通常代表你可以：

  1. 不用看範例，用自己的話解釋「每一行在做什麼」。
  2. 預測程式執行後會出現什麼。
  3. 把同一個觀念換到另一個生活情境。
  4. 程式錯誤時，知道先檢查哪一部分，而不是整段重抄。
