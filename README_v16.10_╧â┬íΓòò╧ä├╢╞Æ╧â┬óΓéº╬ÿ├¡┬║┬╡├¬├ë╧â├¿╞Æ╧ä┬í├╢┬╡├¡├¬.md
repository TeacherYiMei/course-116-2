# v16.10｜學生回顧成功答案

## 新增功能
- 學生可按「📚 回顧已完成挑戰」。
- 清單會列出所有已經完成的主線挑戰。
- 點選後可查看：
  - 原本題目
  - 任務完成條件
  - 自己當時通過檢查的 Python 程式碼
  - 當時檢查輸出（若有）
- 成功答案同時保存於 localStorage 與學生 Firestore 文件的 `successfulAnswers` 欄位。
- 學生換電腦登入相同學習帳號後，可由 Firebase 取回成功答案。

## 舊進度說明
v16.10 以前只保存「完成到哪一題」，並未保存學生的程式碼。
因此舊的已完成題目可以列在回顧清單，但無法還原當時實際答案。
從 v16.10 起，每次正式檢查成功都會保存成功版本。

## 不變
- 主線仍為 26 個挑戰。
- 星星、score、證書條件不變。
- 不會因回顧舊題而倒退進度。
- 不需要修改 Firestore Rules（目前規則允許學生更新自己的非身分欄位）。
