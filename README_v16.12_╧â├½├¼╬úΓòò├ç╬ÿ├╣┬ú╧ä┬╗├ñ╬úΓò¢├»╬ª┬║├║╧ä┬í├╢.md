# v16.12｜前一關範例解答

## 改動
- 移除「保存並回顧學生自己的成功程式碼」功能。
- 不再把學生成功答案寫入 localStorage 或 Firebase `successfulAnswers`。
- 進入下一個挑戰後，會出現「⬅️ 前一關範例解答」。
- 點開後可查看：
  - 前一關題目
  - 任務完成條件
  - 一個完整可行的範例程式
  - 為什麼這樣寫的重點說明
- 範例明確標示「不是唯一答案」。
- 第一個挑戰沒有前一關，因此不顯示按鈕。
- 全部 26 題完成後，可以查看最後一關的範例解答。

## 教學考量
學生只能看到「已經完成的前一關」範例，不會提前看到目前正在作答或後面關卡的完整答案。

## 其他功能不變
- 原 26 題主線
- 主題學習站
- 進階挑戰島自由選關
- 教師後台
- 教師一鍵重設密碼 v16.11
- 星星、score、證書規則

## Firebase
不需要修改 Firestore Rules。
舊資料中如果已有 `successfulAnswers` 欄位，不影響使用；v16.12 起不再新增或更新它。
