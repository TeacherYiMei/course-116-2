# v16.13｜三段式鷹架學習版

## 核心調整
學生主線仍然「不能自由跳關」，維持依序闖關。

每一個 Python 主題固定 3 個挑戰：
1. ① 可複製範例，只改一小部分
2. ② 可複製另一個範例，再改更多地方
3. ③ 不提供可複製程式，由學生自己輸入

如果學生複製後完全沒有修改，正式檢查不會讓他過關。

## 降低難度
- 每一站只聚焦該站的核心指令。
- P9 只練 while 計數，不再混入密碼＋if/elif。
- P10 只練 random.randint()，不再把 random、while、if 組成魔王猜數字。
- 複雜綜合挑戰保留在「進階挑戰島」，不放在主線基礎學習。

## 範例回顧
新增「📚 已完成範例回顧」：
- 只能看已經闖關成功的題目
- 顯示正確參考範例
- 顯示重點說明
- 不保存、也不顯示學生原本答案

## 題數
10 個冒險站 × 每站 3 題 = 30 個基礎挑戰。

既有學生進度不會被清除：
- 原本已完成的數量保留
- 原本只有 2 題的站，會新增第 3 題等待學生完成
