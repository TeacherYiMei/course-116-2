# v16.19｜合法程式可正常執行

## 修正原因
像下面這種程式本來就是合法且符合 P1 題目條件：

```python
print("高雄")
print("看風景")
```

前版正式檢查在 Python 執行成功後還會呼叫 `semanticValidate()`，但該函式未定義，因此可能在成功執行後反而出錯。

## 修正
- 補上穩定的 `semanticValidate()`。
- 不再額外限制合理的地名、活動或文字內容。
- 「▶ 執行看看」只負責執行 Python。
- 「✅ 檢查挑戰」只檢查該題必要的指令與結構，並確認程式能正常執行。
- `print("高雄")`、`print("看風景")` 可正常執行。
- 自由選關、星星、教師端及 Firebase 設定皆不變。

不需要修改 Firestore Rules。
