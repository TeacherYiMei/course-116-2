## 教學定位
「指令小百科」回答：這個指令怎麼寫？
「主題學習站」回答：
1. 為什麼要用這個觀念？
2. 電腦逐行怎麼執行？
3. 這個觀念和前一個觀念有什麼關係？
4. 常見錯誤是什麼？
5. 能不能換一個情境仍然理解？
