# v16.6 錯誤提示加正確範例

學生發生錯誤時，除了指出問題，會再提供「不同情境的正確概念範例」。

## 回饋結構
1. 目前錯在哪裡
2. 為什麼會錯
3. 下一步怎麼修
4. ✅ 不同情境的正確範例
5. 提醒「這不是本題答案」

## 涵蓋
- print / input / 變數
- int / float / 型別轉換
- + - * / // % **
- if / elif / else
- and / or
- for / range
- while
- random / 猜數字
- Python 執行錯誤：縮排、NameError、ValueError、TypeError、SyntaxError、無限迴圈

範例刻意使用與闖關題目不同的內容，避免直接複製答案。
