# 教師學生資料維護

## 教師可做的事
教師登入 `/teacher.html` 後，在學生表格最右側按「🛠️ 維護」。

一般教師只能維護 Firestore `teachers/{uid}.classes` 中授權的班級。
`role: admin` 可維護全部班級。

## 刪除錯誤紀錄
- 單一紀錄：可直接刪除該 Firestore 文件。
- 重複學生：系統仍在主表合併顯示，但維護視窗會列出每一筆原始文件，可只刪除錯的那一筆。
- 刪除前會再次確認。
- 刪除後教師端會重新讀取最新資料。

## 安全規則
`firestore.rules` 已改為：
- 學生仍只能建立／更新自己的文件。
- 任課教師只能刪除自己授權班級的學生文件。
- admin 可刪除所有學生文件。

## Firebase Authentication
教師端刪除的是 Firestore 學習紀錄，不會刪除 Firebase Authentication 使用者。
若某個測試學習帳號也要完全刪除，需由 Firebase Console 的 Authentication 使用者頁面刪除。
