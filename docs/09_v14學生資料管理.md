# v14 學生資料管理

教師端 `/teacher.html` 的「維護」提供四種功能：

1. 關卡明細：查看 P1～P10 各關完成挑戰數。
2. 更正資料：修改班級、座號、姓名。
3. 重設進度：將 Python 學習進度歸零。
4. 刪除紀錄：刪除確認錯誤或重複的 Firestore 文件。

## 權限
- teacher：只能維護 `teachers/{uid}.classes` 授權班級。
- admin：可維護全部班級。
- 若教師把學生從 A 班改到 B 班，A 與 B 都必須在授權範圍內。

## 班級／座號衝突
儲存更正前會查詢同班同座號是否已有其他學生紀錄；若有，停止儲存並提示先處理重複紀錄。

## 學習帳號注意事項
v10 起學生學習帳號使用班級＋座號衍生登入識別。
瀏覽器教師端沒有 Firebase Admin 權限，因此無法修改別人的 Authentication Email。
教師若更正班級或座號，Firestore 會更正，但 Authentication 登入識別不會同步變更。
